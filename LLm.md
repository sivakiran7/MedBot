# What are the metrics of used to measure the ability of an LLM Model?

Task-specific and automated metrics:

Perplexity:   A measure of how well the model predicts a sample of text, indicating its confidence and fluency. 

BLEU and ROUGE:   Metrics that compare the output to a set of reference texts, often used for translation and summarization tasks. 

BERTScore:   An embedding-based metric that captures semantic similarity, going beyond simple word overlap.

F1 Score:   Combines precision and recall into a single metric, useful for tasks like classification. 

Context Precision and Context Recall:   Metrics used to evaluate retrieval-augmented generation (RAG) systems, checking the relevance and completeness of retrieved information.
